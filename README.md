# 青空教室

Delta Chatの同じチャットで、先生が教材を配り、生徒が「わかった！」「わからない」「質問する」で応えるwebxdcミニアプリです。少人数の授業や学習会で、教材と理解度を共有する用途を想定しています。

**対象バージョン：1.0.4**  
README更新日：2026年10月18日

## 配布ファイル

| ファイル | 用途 |

## 主な機能

- タイトル・本文・画像を含む教材の作成と配布。
- 生徒の「わかった！」「わからない」と質問の共有。
- 教材ごとの反応・質問の確認。
- 質問のチャットへの転送、またはコピーの案内。
- 教材のJSONファイルへの書き出しと読み込み。
- HTML単体でのデモ動作。

## はじめ方

### Delta Chatで使う

1. クラス用のチャットに `Aozora-Classroom-1.0.4.xdc` を添付して送ります。
2. 先生と生徒は、**同じチャットの同じアプリのメッセージ**から起動します。
3. 参加画面で、授業で使う名前を入力します。
4. 生徒は「生徒として参加」を1回押します。先生は下記の手順で先生モードに入ります。

アプリを別のメッセージとして新規投稿すると、別の教室になります。別チャットのアプリとも自動では同期しません。

### 先生モードに入る

1. 参加画面で先生の表示名を入力します。
2. 「生徒として参加」を素早く連続で押します。初期設定は **3回**です。
3. 先生モードのパスワードを入力し、「入室」を押します。初期パスワードは **`secret`** です。

生徒画面に入った場合は、右上の「↺」で参加画面に戻って試してください。回数・パスワードを変更した端末では、その端末の設定を使います。

先生モードは操作画面の切替機能です。厳密な本人確認や権限管理ではありません。設定は端末内に保存され、ほかの端末には同期しません。

### 教材を配る

1. 先生画面で「タイトル」と「本文」を入力します。両方とも必要です。
2. 必要に応じて画像を追加します。教材1件につき最大6枚です。
3. 「みんなに配る」を1回押します。
4. 生徒側でも教材が表示されたことを確認します。

画像は長辺800ピクセル以内に縮小され、JPEGに変換されます。小さい文字は読みにくくなる場合があるため、重要な説明は本文にも入力してください。

画像付き教材は分割して順番に送るため、反映まで時間がかかる場合があります。「みんなに配りました」という表示は、全員の受信完了を保証するものではありません。連打せず、アプリを開いて待ってください。

### 生徒が反応や質問を送る

1. 届いた教材を選び、本文や画像を確認します。
2. 「わかった！」「わからない」、または「質問する」を押します。
3. 質問の場合は本文を書き、「質問を送る」を押します。
4. 「あなたのアクション履歴」で内容を確認します。

反応は押すたびに履歴へ追加されます。以前の反応を取り消す操作ではありません。

**質問は先生だけでなく、クラスの参加端末に共有されます。** 個人情報や秘密の相談は入力しないでください。

## 教材を引き継ぐ

### 書き出し

1. 元の教室で先生モードを開き、教材が届き終わるまで待ちます。
2. 教材作成欄の上の「教材の引き継ぎ（書き出し・読み込み）」を押します。
3. 教材件数を確認し、「教材を書き出す」を押します。
4. Delta Chatの案内に従い、JSONファイルを自分で管理する保存先やチャットに保存します。
5. `Aozora-Classroom-backup-日付.json` が残ったことを確認します。

画面が戻ることと、ファイルの保存完了は同じではありません。保存先とファイルの存在を確認してください。

### 読み込み

1. 新しい版や移行先の教室を開き、先生モードに入ります。
2. 「教材の引き継ぎ」から「引き継ぎファイルを選ぶ」を押します。
3. 保存したJSONファイルを選びます。
4. 追加件数・重複件数・教材のタイトルを確認します。
5. 「○件をこの教室に追加する」を押します。
6. 本文と画像を確認し、ほかの参加端末にも届いたか確認します。

既存の教材を残したまま追加します。同じ内容の教材や引き継ぎ済みの教材はスキップし、既存教材を上書き更新しません。読み込んだ教材は、移行先の教室の参加端末に共有されます。

| 項目 | 内容 |
| --- | --- |
| 引き継ぐもの | 教材のタイトル・本文・画像・作成者名・作成日時 |
| 引き継がないもの | 質問・反応・参加者一覧・先生のパスワードと設定・返信済みの印・入力途中の教材 |
| 上限 | 1ファイル50MB、教材1000件まで |
| ファイル形式 | 青空教室が書き出すJSON形式 |

引き継ぎファイル自体にパスワード保護はありません。内容に応じて保存先・送信先を選んでください。引き継ぎを確認するまでは、元の教室とファイルを保管してください。


## 利用上の注意

- 質問の「返信済みにする」は画面内の目印です。返信文を送信せず、端末間の同期や開き直した後の保持もありません。
- 質問の長押しで転送画面を開けます。転送時はチャット側で宛先と内容を確認してください。先生への個別メッセージを自動で保証する機能ではありません。
- 教材の「×」は確認画面なしで削除を送信します。ほかの端末にも反映され、取り消し機能はありません。
- 参加者数・オンライン表示は目安です。出席や全員の受信完了を確認する用途には使えません。
- 「リアルタイム機能有効」は機能を利用できることを示し、相手の接続や受信完了を保証しません。
- 同じアプリを開き直すと、送受信履歴から教材を復元する設計です。授業に使う前に実際の端末で確認してください。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 教材や反応が届かない | 同じチャットの同じアプリを開いているか、Delta Chatの通常メッセージが送受信できるか確認します。 |
| デモモードになる | HTML単体は通信しません。Delta Chatで `.xdc` を起動します。 |
| 画像付き教材だけ遅い | 分割送信に時間がかかります。アプリを開いて待ち、画像を減らして試します。 |
| 先生画面に入れない | 連続タップの速さと、その端末で設定した回数・パスワードを確認します。 |
| 引き継ぎファイルが読めない | 青空教室で書き出したJSONか、50MB・1000件の上限を超えていないか確認します。元の教室で書き出し直して試してください。 |
| 読み込み時に追加が0件になる | 既存教材と重複している可能性があります。追加件数とスキップ件数を確認します。 |

## 確認済みの範囲

コードの構文確認、通信シミュレーション、画像相当の大きなデータの分割・再結合、履歴再生、削除済み教材の再表示防止を確認しています。

引き継ぎ機能では、日本語・画像の書き出しと復元、重複判定、形式検査、読み込み前の確認操作、書き出し時のAPI呼び出しを検証しています。

**実機のDelta Chatでのファイル保存・選択、複数端末の通信、端末ごとの画面表示は未確認です。** 授業に使う前に、先生と生徒の2台で、文字だけの教材・反応・質問・画像付き教材・再起動後の復元・引き継ぎを確認してください。

操作マニュアルの図は説明用の模式図です。PDF版は全11ページを目視確認済みです。Word版は、この作成環境に描画エンジンがないため、実際の改ページを確認できていません。

## アプリの構成

`.xdc` は、次のファイルをルートに置いたZIP形式のパッケージです。

```text
index.html       画面とアプリの処理
manifest.toml    アプリ名とバージョン
icon.png         アプリアイコン
```

配布用HTMLとパッケージ内の `index.html` は同じ内容です。実行時の `webxdc.js` はDelta Chatから提供されるため、パッケージには含めていません。教材・反応はwebxdcの更新メッセージで共有し、リアルタイム通信が利用できる場合は参加状態の通知にも使います。
